Yushin Quote Text is derived from Noto Sans TC, distributed by Google Fonts
(https://github.com/google/fonts/tree/main/ofl/notosanstc). The SIL Open Font
License and Adobe copyright notice appear in OFL-NotoSansTC.txt.

The font keeps the upstream Unicode-to-glyph mappings and advance widths.
Variation and layout tables and glyph outlines were removed with fontTools
to limit the download size. This font is for the invisible quotation PDF
text layer only. The original page image supplies the visible glyphs.
