# 訂單與估價單貨號庫存提示

- 訂單各倉庫可用／現有庫存移到貨號與產品確認狀態下方。
- 估價單每個品項在貨號下方顯示相同資訊，包含產品主檔選入、貨號匹配、載入既有含產品 ID 的品項與 Forecast 帶入。
- 使用已確認的產品 ID 查庫存，避免相同貨號跨廠牌誤取。輸入新貨號或廠牌變更失去產品身分時立即清除舊提示；非同步旧查詢不能覆蓋新的結果。
- 共用既有 warehouseStocks 精確文件讀取及快取，同產品並行查詢只讀一次；不新增 Collection、Listener 或全庫存掃描。
- 失敗不再當成零庫存寫入快取，會提示重新選取貨號重試。原廠直送維持既有說明。
- 只查詢庫存，不預留或變更訂單、採購、庫存與權限。庫存提示使用共用暖灰 CSS 變數與 no-print，不更改正式單據 PDF 產製程式。
