# 直接採購收貨憑證確認修正

正式驗收 PO-YS-20261105-01-02 已完成採購 3、在途 3、收貨 1，公司與又鑫倉均為現有 1、在途 2。原資料重試未重複入庫，但前端持續顯示「到貨待確認」。

不新增讀取、不新增 writer、不改後端交易、權限、Rules、Indexes 或 PDF。庫存數字與冪等由已部署的 receiveV2Supply 負責，前端只確認結果並更新必要畫面。

發布範圍為合併本 PR 後的 GitHub Pages 前端；無需重新部署 Functions 或調整 Firebase 設定。合併 main／正式發布須取得本次額外授權並遵守分支保護與必要 CI。
