# 進銷存分析三分頁

基準：GitHub main 9923e73。只修改讀取、分析計算、畫面與匯出；無資料寫入、資料結構、索引或安全規則變更。

- 採購／銷售：依所選成立日期的單據群組，顯示目前累計履約結果，避免期間交易與全部未完成餘額混用。採購成本缺少時明確標記，不當成零成本。
- 取消／結案採購保留實際到貨，未履約餘額不計入總額；取消訂單保留淨出貨，退貨扣回。這是總額與原始下單總額不同的例外。
- 毛利使用出貨與退貨紀錄的批次成本；直送無批次時僅在唯一對應供應紀錄可確認成本的情況計算。舊資料／缺少成本不宣稱完整毛利。
- 庫存數量以 warehouseStocks 為準；批次成本加總必須與分倉數量一致。預留／可用金額按同品項同倉加權平均成本估值。
- 查詢仍以日期、未完成状态、正餘量條件限制，500 筆游標分批；指定來源文件分組读取。畫面明細 100 筆，匯出完整符合條件資料。長期間／大量現行資料仍會全部加總於瀏覽器。
- 管理員入口及成本讀取既有 Firestore 規則不變；業務、工程師、倉管未獲授權讀取成本。
