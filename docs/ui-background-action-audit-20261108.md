## 共用規則與風險邊界

- 新增共用、**僅影響畫面**的工作狀態：處理中、已確認、已知失敗、結果不明。以使用者／角色／流程／資料 ID 辨識，工作結束即清理已確認狀態。
- 非同步舊快取、即時資料及重新渲染期間，以待處理遮罩維持清單顯示一致，避免圖卡再次出現；不修改 Firestore 資料迎合暫時畫面。
- 已確認失敗可恢復原清單；網路逾時、回覆遺失、無法證明交易未寫入等歸為「結果待確認」，不得直接重送交易。沿用原交易／收貨／寄貨憑證的核對能力。
- 可核對原憑證的訂單取消／恢復及庫存列表移出操作，在全站背景狀態提示提供「核對原操作憑證」；必須帶原交易識別繼續，不會另建新交易。快速採購沿用既有採購復原面板的原憑證按鈕。
- 「結果待確認」不是成功，也不是已證實失敗；目前部分一般主檔操作仍需使用者重新載入並核對權威資料，尚無跨所有模組的自動後端結果查詢契約。不可藉由前端封鎖宣稱後端已具備完全冪等性。
- 本次沒有任何 Firestore 額外查詢、寫入、監聽或新 Cloud Function；背景任務提示完全為瀏覽器記憶體中的暫時介面。
- 保留既有操作輸入、角色限制及商業語意；若切換帳號，背景工作不重新繪製另一帳號畫面。
