# 頁面說明規範

本規範取代 UI／UX 設計規範 1.0 第九條中的分散說明圖示方式。

- 每個主要頁面標題旁只保留一個說明入口，點擊後顯示頁面功能、主要操作與目前角色權限。
- 有工作分頁時，顯示目前分頁名稱及該分頁的補充說明。
- 權限說明沿用程式既有的權限、資料範圍與操作能力判斷，不另外查詢 Firestore，也不改變權限。
- 一般搜尋、選品與操作說明集中呈現，不在欄位或操作區重複放置驚嘆號。
- 錯誤、驗證結果、必要的輸入提示及高風險操作確認仍直接顯示，不能藏入頁面說明。
- 說明支援手機、鍵盤、Esc 關閉及關閉後焦點返回原按鈕。
- 修改功能、流程或權限時，須同步檢查 `modules/page-help.js` 與 `index.html` 的說明內容。
