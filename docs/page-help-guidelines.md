# 頁面說明規範

本規範取代 UI／UX 設計規範 1.0 第九條中的分散說明方式。

- 每個主要頁面只保留一個「！」入口，緊接在主標題右邊，同一排對齊。
- 點擊後只顯示「頁面功能」與「注意事項」；功能一兩句，注意事項兩至四點。
- 必要的角色限制放在注意事項，不另外列出長篇權限表。管理員後台依目前工作分頁顯示相關內容。
- 搜尋、選品與一般操作說明集中呈現，不在欄位或清單重複放圖示，也不常駐大段說明。
- 錯誤、驗證結果、必要輸入提示與高風險確認仍直接顯示。
- 沿用既有權限判斷，不增加 Firestore 查詢，不改變角色權限或商業流程。
- 支援手機、鍵盤、Esc 關閉及關閉後焦點返回原按鈕。
- 修改功能、流程或權限時，同步檢查 `modules/page-help.js` 的簡短說明。
