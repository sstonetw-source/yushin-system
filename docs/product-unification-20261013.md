# 產品、庫存顯示與操作回饋統一

基準：main `c1ee22f`（已整合 2026-10-13 暖灰商務配色更新）。本次為小範圍修正，沿用現有商業流程與角色權限。

## 現行規範來源

- 螢幕介面配色依 `color-palette.md` 的暖灰商務共用變數；較早專案指示中的 `#2563EB` 為舊配色。單據與列印保持既有格式。
- 固定角色及兼任分工依 `role-workflows-20261012.md`：業務、工程師、採購、倉管、管理員。採購可兼任倉庫操作，不代負責業務確認送貨或核銷。
- 系統名詞、核銷日期、取消與交付判斷依 `system-definitions-20261012.md`。
- 本次只在程式庫補充現況索引，不改動 ChatGPT 同步的專案指示檔。

## 本次變更

- 產品詳情以共用庫存核心的 `available` 為準：有分倉事實時加總各倉可用數量；無分倉資料時保留總庫存對調撥途中數量的扣除。預計庫存仍依既有公式。
- 估價／訂單完整貨號比對以 50 筆分頁取得所有同貨號匹配，再做廠牌及唯一性判斷；快取只儲存完整成功結果，不掃描整份產品目錄。
- 倉庫補充產品搜尋依貨號及品名前綴各取 25 筆，使用者按「載入更多產品」才讀下一批。結果去重、排除停用產品，庫存查詢每組不超過 25 個產品。貨號、品名或庫存查詢失敗時不宣稱完整成功，提供重試。
- 搜尋防止同條件重複送出，清除搜尋、切換帳號或角色後，舊請求不能覆蓋畫面。
- 產品搜尋、庫存詳情、成本／售價更新使用共用錯誤說明，提供權限、登入、連線與資料確認的下一步。詳細錯誤留在開發紀錄。
- 大型成本／售價更新中途失敗時，顯示已確認完成的筆數；失敗批次結果保留「待確認」，重新匯入會依既有增量核對流程處理。

## 資料及發布影響

沒有新增 Collection、Listener、Index 或 Rules，沒有調整實際庫存、預留、採購、取消、退貨或調撥的寫入規則。批次更新的寫入內容與順序不變，僅增加失敗時的完成數資訊。產品搜尋增加的讀取限於相符貨號及使用者主動載入的下一批結果。

登入正式系統後的五角色、電腦與手機驗收，以及既有 Rules 是否已同步發布，仍需正式環境確認。
