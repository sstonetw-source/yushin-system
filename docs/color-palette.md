# 暖灰商務配色（B 方案）

使用者於 2026-10-13 選定，取代原霧藍灰配色，作為又鑫管理系統螢幕介面的統一視覺標準。

| 用途 | 色碼 |
| --- | --- |
| 主要操作 | #315C85 |
| 主要操作 Hover | #264A6B |
| 選取背景 | #EDF2F6 |
| 頁面背景 | #F6F5F2 |
| 卡片與表單 | #FDFCFB |
| 導覽背景 | #EEEDE9 |
| 主要文字 | #292D32 |
| 次要文字 | #6B7280 |
| 邊框 | #E7E5E1 |
| 表格標題背景 | #F3F2F0 |
| 成功文字／底色 | #41674C／#EAF3EB |
| 警告文字／底色 | #825B23／#FFF3E4 |
| 危險文字／底色 | #98544F／#FCEDEB |

- 深藍色保留給主要操作；次要操作維持暖白底與低對比邊框，危險操作仍保留紅色。
- 標題、一般文字以深灰為主；已選取工作分頁用淡藍灰。
- 狀態標籤使用淡色背景與清楚文字，不得只以顏色區分。
- 降低表格標題與卡片陰影，保持桌機、手機版一致。
- 所有模組沿用共用 CSS Token，不增加 UI 操作、資料讀取或監聽。
- 不改變估價單、訂購單、PDF 列印格式，不改動資料查詢、權限與商業流程。
- 一般文字對比應至少符合 WCAG AA 4.5:1。
