# 暖砂工作台配色

2026-10-26 起使用暖砂配色。2026-10-27 將手機清單改為「暖褐頁面＋單層暖白資料卡」，避免褐色、淺藍、白色、褐色的巢狀背景交替。以下為 `styles.css` 目前的實際 Token。

| 用途 | 色碼 |
| --- | --- |
| 主要操作 | #315C85 |
| 主要操作 Hover | #264A6B |
| 選取背景 | #EDF2F6 |
| 頁面背景 | #D8D0C3 |
| 面板與估價單編輯表單 | #E9E3D8 |
| 清單資料卡與表格儲存格 | #FDFCFB |
| 一般輸入欄位 | #F0EBE2 |
| 導覽背景 | #C9C0B2 |
| 主要文字 | #2D3336 |
| 次要文字 | #3F494F |
| 邊框 | #B5ADA0 |
| 表格標題背景 | #DFD7C9 |
| 成功文字／底色 | #41674C／#EAF3EB |
| 警告文字／底色 | #825B23／#FFF3E4 |
| 危險文字／底色 | #98544F／#FCEDEB |

- 深藍色保留給主要操作；次要操作維持暖白底與低對比邊框，危險操作仍保留紅色。
- 標題、一般文字以深灰為主；已選取工作分頁用淡藍灰。
- 狀態標籤使用淡色背景與清楚文字，不得只以顏色區分。
- 降低表格標題與卡片陰影，保持桌機、手機版一致。
- 所有模組沿用共用 CSS Token，不增加 UI 操作、資料讀取或監聽。
- 手機清單外層容器保持透明且無額外內距；每筆資料只使用一層暖白卡片。儲存格沿用暖白色，不能覆蓋回面板褐色。
- 淺藍灰 `#EDF2F6` 僅用於選取分頁與必要狀態；庫存被動數值摘要使用中性柔和底色，不表示已選取。
- 不改變估價單、訂購單、PDF 列印格式，不改動資料查詢、權限與商業流程。
- 一般文字對比應至少符合 WCAG AA 4.5:1。
