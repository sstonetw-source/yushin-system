# 重置後開放使用者自行驗收

使用者先授權重置及維護，後續明確改為「不用鎖，我自己測試好再把連結給大家」。
因此解除維護頁與全資料庫封鎖，沿既有登入與固定角色權限開放，不建立額外驗收帳號限制。

- 正式來源的收貨、打單、出貨、送達、取消／恢復、退貨路由與LEGACY_BLOCKED同步切往既有後端。
- production交易旗標啟用，Preview／Emulator旗標仍關閉。
- 正式發布正常firestore.rules；七個settings/*Cutover.backendOnly保留true，禁止舊瀏覽器繼續直接交易。
- 既有十九個函式僅更新十三個已授權交易Callable，其餘函式保持；角色、Auth帳號、主檔與正式PDF不變。
- 本次重置已VERIFIED：315個交易根文件含子集合清除，85個庫存文件歸零，保留主檔及私有完整備份。
- 庫存歸零是使用者測試起點，並不表示公司實際庫存為零；正式期初盤點與五角色驗收仍待完成。
- 自行訂貨、業務保管、待檢轉庫存及未支援的直送邊界不因解除維護而復活舊writer。

發布順序：必要CI／review通過，核對新後端及單向鎖；先更新相容後端，再發布正常Rules，
最後合併前端路由及核對Pages。解除的是全站維護，必要登入、角色及資料一致性防護保留。
