# 採購與訂單資訊一致化

採購待採購、待到貨、待打單、已完成工作，直接顯示已授權來源訂單的含稅銷售單價 × 訂購數量、品項小計、交易方式與發票抬頭。工作數量獨立列為進度，不拿剩餘採購數量當銷售數量。缺少價格或來源資料時顯示待確認，不把供應成本當售價；公司備庫明確顯示沒有客戶銷售／開票資料。

各工作列共用唯讀訂單明細抽屜，列出整張訂單全部品項、訂單總額、交付方式及交易備註。保留既有採購、打單、收貨入口與操作紀錄功能。訂單列表亦直接顯示相同交易／抬頭摘要。手機搜尋欄修正 flex basis 誤成過高欄位的問題。

只使用現有已載入資料，不新增 Query、Listener、Collection、Index 或 Rules，不修改任何交易服務、角色權限、庫存數量或正式 PDF。既有資料未存統編，這次不新增或推測統編欄位。交易方式直接顯示原始值，不推斷借／扣是否應開票。
