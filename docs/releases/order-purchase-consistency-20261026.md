# 訂單、採購各分頁資訊與操作一致性

基準：main 865270f（PR #295）。本次使用者要求把同一原則套用到整個訂單及採購模組。

## 範圍與呈現

- 訂單六個工作分頁共用產品摘要、品項金額公式及操作列。產品欄只顯示品名、廠牌及貨號；金額欄顯示單價乘訂購數量及品項小計。多品項訂單另外明列原始訂單總額，不把目前分頁小計當成訂單總額。
- 採購待採購、待到貨、待打單、已完成共用產品摘要及獨立數量欄，數量分別維持原本待採購、應到貨、待打單、已到貨／已打單定義。不以銷售單價冒充採購成本，不新增成本讀取。
- 採購單歷史的商品欄移除數量，品項金額欄顯示含稅單價乘訂購數量及含稅品項小計。總額保留原有 `Math.round(qty * unitPrice * 1.05)` 計算，沒有修改資料。
- 訂單明細直接列出全部品項，不再收合其他分頁品項；標示目前工作分頁品項並呈現各自工作狀態。保留服務項目專屬待服務處理及原有物流狀態。
- 明細、核銷／已核銷、更多於桌面同列；有其他工作動作時可換行。手機保留 44px 點選範圍。
- 明細中的交付編輯、交易編輯及操作紀錄統一次要操作樣式；展開交易編輯時隱藏重複的唯讀摘要。紀錄按鈕直接開啟既有紀錄視窗。
- 採購清單、歷史、供應商設定、安全庫存補貨共用操作間距與排列；危險操作保留紅色。
- 「我送」顯示用語統一為「業務送」，包含建立訂單的選項及共用交付摘要，儲存代碼未改。

## 資料與權限

只有呈現及既有控制項整理。沿用原查詢、權限、禁用條件與交易函式，沒有新增 Listener、Collection、Index 或 Rules。正式 PDF／列印版型未改。未寫入正式訂單、採購或庫存資料。
