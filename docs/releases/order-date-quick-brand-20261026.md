# 新增訂單當日日期與快速產品廠牌顯示

基準 main：865270f。與 PR #296 的訂單／採購版面整理分開提交。

## 行為

- 新訂單以送出建立時的本機當日日期產生 orderDate；表單不再提供日期選擇。恢復舊草稿不帶回舊日期，開啟表單及存草稿亦使用當日日期。原有已提交作業的復原交易與紀錄不修改。
- 快速建產品原本可輸入廠牌名稱並寫入 products，但產品廠牌按鈕僅由 brands 主檔產生，導致 test 等未列入 brands 的廠牌缺少按鈕。
- 展開產品頁「其他」後，才查詢 products 的 source == QUICK_CREATE，每頁最多 50 筆產品，使用游標按需載入更多並快取。只把啟用產品的真實廠牌補進產品頁，不寫 brands、不變更主要廠牌及公司代理設定。
- 剛儲存的快速產品也立即同步本機廠牌選項。更換帳號、角色或 session generation 時清除這份分頁狀態，過期回應不得帶入新 session。
- 新產品不自動成為常賣品項。點廠牌仍依原規則顯示常賣清單，完整貨號搜尋可找新建產品。

## 技術及安全

- 現有 yu-shing-company / (default) 已讀取資料庫中繼資料，確認為 Firestore Standard。
- 使用既有 products 讀取權限，查詢前檢查產品頁權限。僅新增按需、分頁讀取，沒有全目錄掃描、Listener、Collection 或寫入廠牌主檔。
- source 單欄等值查詢及文件游標使用現有自動索引；repository 無排除此欄位的 fieldOverride。不需新增複合 Index，不修改 Rules。
- 未讀寫正式產品、訂單或庫存資料。測試使用腳本化資料，正式環境交易未實測。
