# 訂單與採購介面、直接採購操作及成本率（2026-11-05）

基準：`059dfd40`（最新 main，含 PR #466）。本分支不重新實作 #466 的直接採購收貨憑證修正。

## 實際變更與操作

- 訂單金額以「NT$ 5,000 × 1＝NT$ 5,000」顯示，稅別集中於標題；核銷文字移到進度，狀態定義不變。
- 沿用共用列表與暖灰變數；客戶連結頂端對齊並保留 44px 點擊高度。手機沿用卡片，採購編輯列使用資料標籤。
- 採購／管理員的直接採購沿用原視窗，編輯順序為貨號、廠牌、品名、入庫倉庫、數量、未稅進貨單價、小計。正式 PDF 的獨立產生函式與表格順序未修改。
- 相同貨號有多筆有效商品時，一律明確選擇商品；不任取第一筆。使用原主檔查詢與成本讀取，不建立第二套商品或採購核心。
- 可設定整張單的預設入庫倉庫並逐列調整；不可選寄庫等非實體入庫倉庫。沿用有效商品／供應商主檔及原數量、零元成本規則。
- 「儲存草稿」與「下載 PDF」均為次要操作。「確認已採購」可從新單直接儲存文件後，進入原採購確認及在途登記，不依賴 PDF 或下載資料夾權限。
- 確認中的重複點擊受阻擋；原 session checkpoint、原單號與既有後端操作識別不變。失敗訊息區分採購確認與在途登記，透過原「確認前次採購結果」重試。
- 確認後沿用原待到貨供應快取及倉庫收貨入口。無客戶來源的供應顯示「庫存」、採購單號、供應商、實際入庫倉庫及成本；銷售金額為「—」。可搜尋採購單號及供應商。支援原部分收貨。

## 成本率與資料影響

使用者已明確選擇：成本率＝採購成本／銷售金額 × 100%，不將此比值稱為利潤或毛利率。

成本與比較明細放在可展開區域。供應成本原為未稅單價，顯示時呼叫既有 `purchaseAmountMetadata`，沿用 5% 稅別與原文件取整規則換為含稅；銷售單價沿用原含稅定義。以相同採購數量計算成本與比較銷售額，不拿整筆訂單銷售額比較部分採購。仍標示「預估」，不聲稱已實現毛利。

缺少已載入且可靠的成本時顯示「待確認」，合法零成本仍為零；零或缺少銷售額時成本率為「—」。直接備庫只顯示成本，銷售與成本率為「—」。舊採購文件缺少成本時保留未知，讀取時不轉為零。

不新增逐列查詢或 Listener；只使用已獲權限並載入的原供應快取／採購文件。歷史來源銷售資料未載入時不推測銷售額。採購成本資料仍由既有 `canPurchase()` Rules 與去成本的 `receivingSupplyOrders` 分流保護，不只是前端隱藏。

不建立假客戶、客戶訂單、銷售、應收或預留；不修改安全庫存補貨來源定義。文件儲存、採購確認、在途、收貨保留原交易邊界與庫存增減規則。未重置或修改正式驗收資料。
