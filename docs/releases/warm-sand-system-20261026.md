# 暖砂共用介面與字型整理

以 2026-10-26 main（dfa7266，PR #294）為基準。使用者選定暖砂工作台，要求全系統字型、字級與標題位置一致。

## 實際變更

- 所有工作模組共用暖砂頁面、卡片、導覽、欄位及表頭色票；主操作維持深藍，選取維持淡藍灰，危險操作保留紅色。
- 共用字型順序為 Noto Sans TC、PingFang TC、Microsoft JhengHei 及系統字型，不額外下載字型。
- 頁面標題電腦 24px、手機 22px，統一左緣、上方位置與下方間距；控制項、表格使用共用字級。
- 估價單編輯欄位採暖砂輸入底色，增加閱讀尺寸與 44px 點選高度；手機欄位使用 16px，並修正品項卡片寬度與內容裁切。
- 僅螢幕工作區調整。估價單三種 PDF 主題及估價單／採購單正式列印格式維持原樣。
- 不變更權限、交易、Firestore 查詢、Listener、Rules、Index 或資料模型。各角色操作流程不變。

## 驗證

- 靜態：產生程式一致性及 diff 空白檢查。
- 自動化：一般應用程式回歸測試。
- 本機實際 Chrome：八個主模組於 1440／1024／390px 的標題位置、字型、字級與欄位；有品項的估價單手機卡片與輸入。
- 本機實際 Chrome：17 類共用控制項、四種採購工作清單、訂單品項進度、訂單輸入與原有五角色顯示限制。
- 與修改前 CSS 比對三家估價單 PDF 內容，以及估價單／採購單 print media 的字型、尺寸、顏色與邊框。這是瀏覽器樣式比對，沒有連接正式資料或實際建立正式單據。
- 未執行正式環境交易測試；本次為 CSS 及其快取版本調整，無需更動 Firebase 設定。
